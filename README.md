### Hi, I'm Leha Mohan

I'm a Senior SDET / QA Automation Engineer based in Dallas, TX, with about 8 years in quality engineering, mostly in **banking** and **healthcare**. What I focus on:

- Framework design that stays maintainable as a suite grows: Page Object Model, fixtures, data-driven tests, clear reporting
- API and contract testing for money-movement and claims/eligibility style workflows
- Putting tests in the pipeline: parallel runs, sharding, containerised runners, reports that people actually open
- Using AI assistants (GitHub Copilot, ChatGPT) to speed up test design, with human review before anything lands in a suite
